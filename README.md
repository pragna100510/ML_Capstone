
# ML Capstone Project – Review 1

This repository contains the **Review 1 submission** for the **23CSE301 Machine Learning Capstone Project** at **Amrita Vishwa Vidyapeetham**. The project implements a complete machine learning pipeline, including data loading, exploratory data analysis (EDA), preprocessing, feature engineering, model training, evaluation, hyperparameter tuning, and visualization.

## Datasets Used

### Regression Dataset
**Diamond Price Prediction Dataset**

- **Objective:** Predict the price of a diamond using features such as carat, cut, color, clarity, depth, table, and dimensions (`x`, `y`, `z`).

### Classification Dataset
**Customer Personality Analysis Dataset**

- **Objective:** Classify customer behaviour using demographic and spending-related features.

## Project Contents

- Dataset loading and audit.
- Exploratory Data Analysis (EDA) with visualizations and insights.
- Data preprocessing (missing values, duplicates, outliers, encoding, scaling, and train-test split).
- Feature engineering.
- Implementation of **10 Regression algorithms**.
- Implementation of **5 Classification algorithms (Part A)**.
- Model evaluation using comparison tables and performance metrics.
- Hyperparameter tuning and result visualizations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## How to Run

1. Clone this repository.
2. Install the required libraries using `requirements.txt`.

   ```bash
   pip install -r requirements.txt
   ```

3. Open `regression.ipynb` or `classification.ipynb` in Jupyter Notebook.
4. Run all cells from top to bottom to reproduce the results and visualizations.
